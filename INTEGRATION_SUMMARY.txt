🔄 CHECKOUT FLOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Customer browses books
2. Clicks "Add to Cart" → Item saved to localStorage
3. Goes to /cart.html → Reviews items, updates quantities
4. Fills billing form → Shipping/billing details
5. Clicks "Proceed to Payment" → Redirects to /checkout.html
6. Enters card details → Stripe payment form
7. Clicks "Pay Now" → Payment processed via Stripe
8. Redirects to /order-confirmation.html → Success page
9. Order confirmation displayed → Cart cleared
10. Customer can continue shopping or go home

🚀 QUICK SETUP
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Get Stripe keys: https://dashboard.stripe.com/test/apikeys
2. Update checkout.html line 145 with your publishable key
3. Run: npm install
4. Deploy: vercel --prod
5. Add environment variables in Vercel dashboard:
   - STRIPE_SECRET_KEY=sk_test_...
   - STRIPE_PUBLISHABLE_KEY=pk_test_...
