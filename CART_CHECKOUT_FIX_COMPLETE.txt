🔄 HOW IT WORKS NOW
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. User clicks "Add to Cart" button
   ↓
2. cart-integration.js detects the click
   ↓
3. Extracts product data (title, price, image, quantity)
   ↓
4. Saves to localStorage as 'bookloop_cart'
   ↓
5. Shows green notification: "Added to cart!"
   ↓
6. Updates cart count in header
   ↓
7. User can:
   - Continue shopping
   - Click cart icon to view cart (/cart.html)

        - See total in USD

Step 3: Enter Billing Details
        - First/Last Name
        - Email
        - Address, City, State, ZIP
        - Phone Number

Step 4: Proceed to Payment (/checkout.html)
        - Review order summary
        - Verify billing address
        - Enter card details (Stripe form)

Step 5: Complete Payment
        - Stripe processes payment in USD
        - Redirect to confirmation

Step 6: Order Confirmation (/order-confirmation.html)
        - See order ID
        - Order details
        - Items purchased
        - Total paid
        - Options: Continue Shopping / Go Home

⚠️  IMPORTANT NOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Cart data is stored in browser localStorage
   - Persists across page reloads
   - Cleared when user completes order
   - Can be manually cleared via console

2. Product data is extracted from page DOM
   - Title: From h1, h2, h3, h4, .product-title
   - Price: From .price, .money, .price-product-detail
   - Image: From first img tag in product container
   - Quantity: From form input[name="quantity"]

3. If product data extraction fails:
   - Falls back to meta tags
   - Uses page title as product name
   - Checks og:price:amount for price
   - Uses og:image for image

4. Cart icon link should point to /cart.html
   - Edit header template if needed
   - Add class="cart-link" to cart icon
