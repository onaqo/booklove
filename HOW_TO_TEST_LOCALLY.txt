❌ THE PROBLEM
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You're opening files directly in browser using file:// protocol:
  ❌ file:///Users/knowadi/Downloads/booklove/index.html

This causes CORS errors and prevents:
- JavaScript from running properly
- Cart system from working
- API calls from functioning
- LocalStorage from working correctly

✅ THE SOLUTION: USE A LOCAL WEB SERVER
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

You MUST run the site on a web server (http://localhost).

🚀 OPTION 1: USE THE STARTUP SCRIPT (EASIEST)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Terminal and run:

    cd /Users/knowadi/Downloads/booklove
    ./START_LOCAL_SERVER.sh

Then open in browser:
    http://localhost:8000

To stop: Press Ctrl+C in Terminal

🚀 OPTION 2: PYTHON 3 (IF YOU HAVE IT)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Terminal:

    cd /Users/knowadi/Downloads/booklove
    python3 -m http.server 8000

Then open: http://localhost:8000

🚀 OPTION 3: NODE.JS SERVE (IF YOU HAVE NODE)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Terminal:

    cd /Users/knowadi/Downloads/booklove
    npx serve -p 8000

Then open: http://localhost:8000

🚀 OPTION 4: PHP (IF YOU HAVE IT)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Open Terminal:

    cd /Users/knowadi/Downloads/booklove
    php -S localhost:8000

Then open: http://localhost:8000

━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

⚠️  COMMON ERRORS (IF NOT USING LOCAL SERVER)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

These errors mean you're using file:// instead of http://:

❌ "Cross origin requests are only supported for protocol schemes..."
❌ "Access to XMLHttpRequest at 'file:///.well-known/shopify/..."
❌ "Access to fetch at 'file:///api/collect'..."
❌ "POST file:///cart/add.js net::ERR_FAILED"

All of these are fixed by using a local web server!

📝 WHAT ABOUT THOSE SHOPIFY API ERRORS?
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The errors about:
- /.well-known/shopify/monorail/v1/produce
- /api/collect
- /cart/add.js
- /search?q=...

These are from old Shopify tracking scripts and won't work on a static site.
They're HARMLESS and can be ignored. They don't affect our new cart system.

To hide them (optional):
1. They'll disappear once you deploy to a real server
2. Or you can remove the Shopify analytics scripts (but not necessary)

🎯 OUR CART SYSTEM IS SEPARATE
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Our BookLoopCart system uses:
✓ localStorage (works on http://)
✓ jQuery (already loaded)
✓ Pure JavaScript (no external APIs needed)
✓ Stripe for payments (works on http:// and https://)

It does NOT depend on:
✗ Shopify APIs
✗ /cart/add.js
✗ Old theme cart system

🚀 DEPLOYING TO PRODUCTION
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Once tested locally, deploy with Vercel:

    npm install
    vercel login
    vercel --prod

Then add Stripe keys in Vercel Dashboard.

On the live site (https://...), everything will work perfectly
with no CORS errors!
